Automatically clears the WooCommerce cart after a specified time of inactivity.

== Description ==

The Auto Clear Cart plugin for WooCommerce helps to automatically clear the shopping cart after a defined period of inactivity. This ensures that abandoned carts are cleaned up, improving store performance and user experience.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/auto-clear-cart` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Configure the inactivity timeout in the plugin settings.

== Frequently Asked Questions ==

= How do I configure the inactivity timeout? =
Go to WooCommerce > Settings > Auto Clear Cart to set the timeout duration.

= Will this plugin affect logged-in users? =
Yes, the cart will be cleared for all users after the specified inactivity period.
